WOSVIP
Launcher

A desktop launcher project for Minecraft: Java Edition, focused on managing game installations, Fabric profiles, and mods in one place.

C# / .NET 8Avalonia UIWindowsLinux support planned

Project overview

Java installations

Manage separate game profiles and installation requirements, including the project's Minecraft Java 1.21.11 + Fabric configuration.

Mods and profiles

A dedicated interface for mod folders, game profiles, and future installation management.

Account authentication

Integration under development using Microsoft account sign-in, Xbox Live, XSTS, and Minecraft Services. Minecraft Services application authorization is pending.

Authentication and licensing

WOSVIP Launcher is intended for users with legitimate Minecraft licenses. The project aims to use standard Microsoft authentication and Minecraft entitlement validation. It does not intend to bypass account login, ownership checks, or other security controls.

Development status: authentication integration is under review. The launcher is not presented as a finished or officially approved product.
